## Installation

Clone this repository:
```
git clone

cd ai-virtual-psyche-hotel
```

Using `pip` and `venv`:
```
# Create virtual environment
python -m venv venv

# Activate virtual environment
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install flask anthropic python-dotenv

# Configure (optional) 
cp .env.example .env
# Edit .env with your API key

# Run the app
python virtual_hotel_app.py
```

Alternatively, using `uv`:
```
uv init

# Create virtual environment
uv venv

# Install dependencies
uv pip install flask anthropic python-dotenv

# Configure (optional) 
cp .env.example .env
# Edit .env with your API key

# Run the app
uv run virtual_hotel_app.py
```

The app will be avialable at [http://127.0.0.1:5000](http://127.0.0.1:5000)

# Claude's Description

A cyberpunk-inspired virtual hotel experience that creates AI-generated "psychic interiority" profiles based on biometric and digital data streams. Built with Flask and featuring a futuristic web interface.

## Features

- **Virtual Room Check-in/Check-out System**: Users can reserve their own virtual room in the hotel grid
- **Biometric Data Simulation**: Each room generates realistic mock data including:
  - Sleep duration and patterns
  - Skin temperature and heart rate
  - Ambient room conditions
  - Connected device networks
  - Internet traffic patterns
- **AI-Powered Interpretations**: Integration with Claude AI to generate poetic, atmospheric descriptions of users' "psychic interiority" based on their data streams
- **Cyberpunk UI**: Retro-futuristic interface with neon green highlights, geometric styling, and smooth animations
- **Service Desk**: System monitoring dashboard showing AI model status and API call logs
- **Real-time Updates**: Auto-refreshing data streams and hotel occupancy status

## How to Use

### Basic Operations

1. **Check In**: Click "Check In" to reserve your virtual room (highlighted in green)
2. **Explore Rooms**: Click on any room to view detailed biometric data streams
3. **View Interpretations**: Each room displays an AI-generated atmospheric description of the occupant's inner state
4. **Update Data**: Use the "Update Data Stream" button to refresh biometric readings
5. **Service Desk**: Toggle the service desk to monitor system status and API logs
6. **Check Out**: Click "Check Out" to leave the hotel

### Interface Guide

- **Green Room**: Your checked-in room (only visible when you're checked in)
- **Gray Rooms**: Other occupied rooms in the hotel
- **Pulsing Dots**: Indicate active data streams
- **Service Desk**: System monitoring and AI status information

## Architecture

### Backend (Flask)

- **Database**: SQLite with tables for rooms, hotel state, and API logs
- **AI Integration**: Anthropic Claude API for generating interpretations
- **Session Management**: Flask sessions for user state tracking
- **Data Generation**: Realistic biometric and digital activity simulation

### Frontend

- **Pure HTML/CSS/JavaScript**: No external frameworks
- **Responsive Grid**: Dynamic room layout that expands as needed
- **Modal System**: Detailed room inspection interface
- **Real-time Updates**: 30-second auto-refresh cycle

### Key Components

**virtual_hotel_app.py** - Main Flask application containing:
- VirtualHotel class - Core hotel management logic
- DataStream dataclass - Biometric data structure  
- Database functions - SQLite operations
- API routes - REST endpoints

**templates/index.html** - Complete frontend interface

## API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/` | GET | Main dashboard interface |
| `/check_in` | POST | Reserve a room for current user |
| `/check_out` | POST | Release user's room |
| `/hotel_state` | GET | Get all rooms and occupancy data |
| `/room/<id>` | GET | Get detailed room information |
| `/service_desk` | GET | System status and API logs |
| `/update_room/<id>` | POST | Refresh room's data stream |


## AI Integration

The Virtual Hotel uses Anthropic's Claude AI to generate atmospheric, poetic interpretations of biometric data. The system includes:

- **Intelligent Fallbacks**: Rich contextual interpretations when no API key is provided
- **Performance Monitoring**: Response time and error tracking
- **Contextual Analysis**: Data-driven interpretation generation based on sleep patterns, heart rate, time of day, and digital activity

## System Status

The Service Desk provides real-time monitoring of:

- AI model connectivity and performance
- API call success/failure rates and response times
- Room data update frequencies
- System resource usage

## Privacy & Ethics

This project generates **mock biometric data only** and does not:

- Collect real personal or health information
- Store sensitive user data
- Connect to actual biometric devices
- Share data with external services (beyond optional AI API calls)
